# 慧文融通人工验收套件

本目录用于业务验收、演示和回归测试，覆盖信息提取、文档编辑和表格填充三类核心能力。测试材料按 `01-入门` 至 `05-极限` 组织，共 15 个场景。

## 适用范围

- Web 与 Android 的核心业务流程；
- API、Worker、数据库和文件交付组成的完整闭环；
- 真实模型模式或明确标记的模拟模式；
- 新版本发布前的回归和现场演示预演。

自动化测试通过不代表业务验收已经完成。人工验收须核对输入材料、过程状态、证据记录、质量报告与最终交付文件，不得仅以页面可访问作为通过标准。

## 目录

- [信息提取](01-信息提取/README.md)：字段识别、归一化、冲突处理和证据追溯；
- [文档编辑](02-文档编辑/README.md)：内容修改、格式控制、脱敏和复杂结构重组；
- [表格填充](03-表格填充/README.md)：字段映射、公式、多源融合、去重和异常追溯。

完整场景索引、目录位置、核心考点和建议分值见 `测试用例总表.xlsx`。

## 验收前准备

1. 确认 `/health/ready` 返回就绪，Worker 正常运行；
2. 使用专用测试账号，禁止使用生产账号或生产文件；
3. 完整记录版本、分支、客户端、设备、后端地址与模型配置；
4. Android 实体设备测试须确认网络连接与 API 环境；ADB 隧道结果不得作为生产网络验证依据；
5. 期望结果只用于核对，不能上传给系统作为输入。

## 执行顺序

1. 从目标功能的入门场景开始，逐级执行到极限场景；
2. 按场景中的要求上传源材料、模板和任务说明；
3. 在任务中心检查排队、执行、成功或失败状态，以及真实节点时间线；
4. 核对证据来源、质量报告、下载文件和重新进入后的历史记录；
5. 针对冲突、缺失、重复与异常数据，确认系统未生成缺乏来源依据的内容；
6. 记录结果、截图、任务 ID、失败步骤和日志时间点。

## 跨端验收

每个场景至少选择一项任务，分别在 Web 与 Android 客户端执行或查看，并重点核验以下内容：

- 功能入口、字段和任务参数含义一致；
- 状态、错误、重试和取消语义一致；
- 任务记录和下载结果在两个客户端可互相查看；
- 平台特有的文件选择、返回导航和权限提示符合系统习惯。

## 评分建议

- 正确性 50%：字段、内容、数值、公式和版式满足要求；
- 可追溯性 20%：关键结果能够定位到来源材料；
- 稳健性 15%：冲突、缺失、重复和噪声处理合理；
- 交付质量 15%：输出文件可打开、结构未损坏、格式清晰。

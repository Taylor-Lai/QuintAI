# QuintAI 分级测试套件

本目录用于人工验收、演示和回归测试，共 5 个难度等级、15 个测试用例，覆盖信息提取、文档编辑和复杂表格填充。

## 使用顺序

1. 从 `01-入门` 开始，确认上传、执行、下载和结果查看链路可用。
2. 依次执行进阶、困难、挑战和极限用例。
3. 信息提取用例以 `期望结果.json` 为对照；文档编辑和表格填充用例以 `期望结果.docx/xlsx` 为对照。
4. 在执行中心检查真实节点进度、质量报告与证据来源；存在冲突或缺失值的用例不应被系统静默臆造。

## 评分建议

- 正确性 50%：字段、数值、公式和版式满足要求。
- 可追溯性 20%：关键结果能够定位到来源材料。
- 稳健性 15%：冲突、缺失、重复和噪声处理合理。
- 交付质量 15%：输出文件可打开、结构未损坏、格式清晰。

详细用例、预期行为和建议分值见 `测试用例总表.xlsx`。

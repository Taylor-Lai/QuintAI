# QuintAI 测试套件

本目录用于人工验收、演示和回归测试，共 3 类功能、5 个难度等级、15 个测试用例。

## 目录结构

- `01-信息提取`：验证字段识别、归一化、冲突处理和证据追溯。
- `02-文档编辑`：验证内容修改、格式调整、信息保护和复杂文档重构。
- `03-表格填充`：验证直接映射、公式计算、多源融合和异常追溯。

每个功能目录均按照 `01-入门`、`02-进阶`、`03-困难`、`04-挑战`、`05-极限` 排列，测试时无需在不同功能之间切换。

## 使用顺序

1. 先选择要验收的功能，再从该目录的入门用例逐级执行到极限用例。
2. 按用例目录中的要求上传材料并执行任务，不要将期望结果文件作为输入。
3. 信息提取以 `期望结果.json` 为对照；文档编辑和表格填充以 `期望结果.docx/xlsx` 为对照。
4. 在执行中心检查真实节点进度、质量报告与证据来源；遇到冲突、缺失或重复数据时，系统不得静默臆造。

## 评分建议

- 正确性 50%：字段、数值、公式和版式满足要求。
- 可追溯性 20%：关键结果能够定位到来源材料。
- 稳健性 15%：冲突、缺失、重复和噪声处理合理。
- 交付质量 15%：输出文件可打开、结构未损坏、格式清晰。

完整索引、目录位置、核心考点和建议分值见 `测试用例总表.xlsx`。

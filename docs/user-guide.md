# 慧文融通使用指南

本指南适用于通过 Web 或 Android 客户端使用慧文融通执行文档处理任务的用户。两个客户端共享账号体系、任务记录与服务端处理结果；界面布局根据设备形态进行适配，任务状态与交付内容保持一致。

## 开始使用

1. 打开管理员提供的 Web 地址，或安装对应环境的 Android 应用；
2. 注册账号或使用已有账号登录；
3. 从首页进入所需能力，或在工作台查看文档、复核、工作流和知识记录；
4. 任务提交后，处理进度将持续记录于任务中心，无须保持当前页面开启；
5. 任务完成后，应核验质量报告与证据记录，再下载或使用处理结果。

任务记录在 Web 与 Android 之间同步。已完成、失败或已取消的记录可以删除；删除操作同时清理服务端管理范围内的结果文件且不可恢复，运行中的任务须先取消。团队自定义模板同样保存在服务端，创建或修改后可在两个客户端使用。

所有 AI 处理入口和计划任务均计入当前组织的周期运行额度。套餐及资源额度由平台管理员依据授权配置；达到上限时系统会拒绝新任务，但不会生成无法执行的任务记录。用户可在企业控制台查看当前套餐、用量和限制。

禁止上传未经授权处理的文件。涉及个人信息、合同、财务或其他敏感内容时，须遵循所属组织的数据授权、访问控制与保存期限要求。

## 文档智能操作

该功能用于按照自然语言要求修改 Word 文档。

1. 上传 `.docx` 文件；
2. 明确描述修改对象、目标属性与执行动作，例如“将标题加粗并设为红色，将第二段字号设为 16 磅”；
3. 提交后在任务详情查看处理节点；
4. 下载结果并使用 Word 或兼容软件检查内容、表格、分页和未要求修改的区域。

单条指令包含多个操作时，建议使用分号分隔。系统检测到操作未实际生效时将任务标记为失败；失败任务的输出不得作为正式交付文档使用。

## 信息智能提取

该功能用于从 Word、Excel 或文本材料中提取指定字段。

1. 上传来源文件；
2. 填写需要提取的字段，每个字段应有明确业务含义；
3. 任务完成后检查字段值、置信信息、证据片段和质量提示；
4. 对缺失、冲突或低置信字段进行人工复核。

字段成功生成不代表内容已完成业务核验。金额、日期、身份信息和合同条款等关键字段必须结合证据位置进行人工复核。

## 多源表格填充

该功能用于将一个或多个来源文件中的数据映射并写入指定 Excel 模板。

1. 上传空白模板和全部来源文件；
2. 说明筛选、排序、合并、计算或日期范围要求；
3. 等待系统完成解析、映射、计算、验证和写入；
4. 下载 Excel，检查行数、字段、日期、公式、重复项和原模板格式；
5. 结合质量报告处理缺失值、来源冲突和无法自动确认的数据。

模板文件与期望结果文件具有不同用途。期望结果仅用于验收核对，不得作为来源材料上传。

## 知识与证据中心

该功能用于组织已上传文档，并通过可追溯检索和实体关系定位跨文档信息。

1. 创建知识库并选择检索模式；
2. 从工作台选择文档加入知识库，系统将建立文档片段索引；
3. 对文档执行信息提取后，系统会将规范化字段同步为实体、关系和证据；
4. 在“证据检索”中输入问题或关键词，查看命中文档、来源片段及关联路径；
5. 在“知识图谱”中按名称或实体类型筛选节点，选择节点查看关系和原文证据，并将实体标记为“已确认”或“存疑”；
6. 文档或抽取结果发生变化后，可选择“重新构建”同步最新数据。

知识图谱用于关联和定位证据，不替代原始材料。关系路径、置信度和自动归并结果均应结合来源文档核验，尤其是同名人员、简称机构以及金额、日期等关键字段。

## 任务状态

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 排队中 | 任务已提交，等待 Worker 接收 | 避免重复提交，可在适当间隔后刷新状态 |
| 处理中 | 系统正在执行真实处理节点 | 在任务详情查看当前阶段 |
| 已完成 | 结果与质量信息已经生成 | 核对证据和文件后下载 |
| 失败 | 文件、指令、模型或服务处理未完成 | 查看失败原因，修正输入后重试 |
| 已取消 | 用户或系统已停止任务 | 确认是否需要重新创建 |

重复触发提交操作可能创建多条任务。发生网络波动时，应先在任务中心确认任务记录是否已生成。

## Web 与 Android 的差异

- Web 适用于批量上传、复杂表格核验与桌面端管理场景；
- Android 适用于进度查询、业务复核与移动场景下的轻量任务处理；
- 手机文件选择器、返回方式和系统权限提示遵循 Android 规范；
- 两端显示不一致时，以服务端任务详情和最终下载文件为准，并记录任务 ID 反馈问题。

## 常见问题

- **任务持续处于“排队中”**：确认服务状态与 Worker 运行状态，避免连续重复提交；
- **任务执行失败**：在任务详情中定位失败阶段，并检查文件格式、文件大小与任务指令是否符合要求；
- **字段为空**：核对来源文件是否包含该信息，并查看证据与质量提示；
- **Android 无法连接**：确认应用安装包对应正确环境；本地调试方法见 [Android 原生端说明](../android-app/README.md)；
- **无法下载结果**：确认任务已完成、账号仍有访问权限，并检查浏览器或系统存储权限；
- **结果需要业务确认**：通过人工复核完成修正并记录说明，禁止直接覆盖来源材料。

# 慧文融通使用指南

本指南适用于通过 Web 或 Android 使用慧文融通处理文档的用户。两个客户端共用账号、任务记录和服务端结果；页面布局会因设备不同而变化，但任务状态和交付内容保持一致。

## 开始使用

1. 打开管理员提供的 Web 地址，或安装对应环境的 Android 应用；
2. 注册账号或使用已有账号登录；
3. 从首页进入所需能力，或在工作台查看文档、复核、工作流和知识记录；
4. 提交任务后可离开当前页面，处理进度会保存在任务中心；
5. 任务完成后先核对质量报告和证据，再下载或使用结果。

不要在生产环境上传无权处理的文件。涉及个人信息、合同、财务或其他敏感内容时，应先确认所在组织的授权与保存规则。

## 文档智能操作

该功能用于按照自然语言要求修改 Word 文档。

1. 上传 `.docx` 文件；
2. 清楚描述要修改的对象和动作，例如“将标题加粗并设为红色，将第二段设为 16 号”；
3. 提交后在任务详情查看处理节点；
4. 下载结果并使用 Word 或兼容软件检查内容、表格、分页和未要求修改的区域。

一条指令包含多个动作时，建议使用分号分隔。系统发现动作未实际生效时会将任务标记为失败，不应把失败结果当作已完成文档。

## 信息智能提取

该功能用于从 Word、Excel 或文本材料中提取指定字段。

1. 上传来源文件；
2. 填写需要提取的字段，每个字段应有明确业务含义；
3. 任务完成后检查字段值、置信信息、证据片段和质量提示；
4. 对缺失、冲突或低置信字段进行人工复核。

系统不会因为字段已填写就保证内容一定正确。重要结果应回到证据位置核对，尤其是金额、日期、身份信息和合同条款。

## 多源表格填充

该功能用于把一个或多个来源文件整理到 Excel 模板中。

1. 上传空白模板和全部来源文件；
2. 说明筛选、排序、合并、计算或日期范围要求；
3. 等待系统完成解析、映射、计算、验证和写入；
4. 下载 Excel，检查行数、字段、日期、公式、重复项和原模板格式；
5. 结合质量报告处理缺失值、来源冲突和无法自动确认的数据。

模板和期望结果不是同一类文件。期望结果只应用于验收核对，不应作为来源文件上传。

## 任务状态

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 排队中 | 任务已提交，等待 Worker 接收 | 无需重复提交，可稍后刷新 |
| 处理中 | 系统正在执行真实处理节点 | 在任务详情查看当前阶段 |
| 已完成 | 结果与质量信息已经生成 | 核对证据和文件后下载 |
| 失败 | 文件、指令、模型或服务处理未完成 | 查看失败原因，修正输入后重试 |
| 已取消 | 用户或系统已停止任务 | 确认是否需要重新创建 |

重复点击提交可能创建多条任务。网络波动时应先到任务中心确认任务是否已经存在。

## Web 与 Android 的差异

- Web 更适合批量上传、复杂表格核对和桌面端管理；
- Android 更适合查看进度、处理复核和移动场景中的轻量任务；
- 手机文件选择器、返回方式和系统权限提示遵循 Android 规范；
- 两端显示不一致时，以服务端任务详情和最终下载文件为准，并记录任务 ID 反馈问题。

## 常见问题

- **一直显示排队中**：确认服务状态和 Worker 是否运行，不要连续重复提交；
- **任务失败**：打开任务详情查看失败阶段，检查文件格式、大小和指令是否明确；
- **字段为空**：核对来源文件是否包含该信息，并查看证据与质量提示；
- **Android 无法连接**：确认应用安装包对应正确环境；本地调试方法见 [Android 原生端说明](../android-app/README.md)；
- **无法下载结果**：确认任务已完成、账号仍有访问权限，并检查浏览器或系统存储权限；
- **结果需要业务确认**：在人工复核中修正并留下说明，不要直接覆盖来源材料。

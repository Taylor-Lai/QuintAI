# 发布就绪检查

本文档规定慧文融通候选版本的统一发布门禁，并记录当次验证结果。每个候选版本均须重新执行全部适用检查，并记录分支、提交、验证环境与日期。

## 发布门槛

- 产品名称、应用名称、页面标题和用户文案统一使用“慧文融通”；QuaintAI 只作为团队或技术命名空间出现；
- API、Worker、PostgreSQL 和 Redis 健康，数据库迁移可执行，任务文件卷可写；
- 后端单元与集成测试、Ruff、Mypy、表格引擎评测全部通过；
- Web lint、生产构建、依赖审计和真实浏览器核心流程通过；
- Android 单元测试、Lint、Debug 构建和已授权真机核心流程通过；
- 信息提取、Word 编辑、表格填充至少各完成一个真实端到端任务，并核对最终文件内容；
- 生产域名、HTTPS、CORS、模型凭据、数据库备份和 Android 发布签名已配置；
- 不包含 `.env`、密钥、签名文件、真实用户数据、上传文件、数据库或构建产物。
